# Решения ФАС и УФАС о заточке технического задания (44-ФЗ)

Обезличенный реестр 1 553 решений антимонопольной службы по жалобам на описание объекта закупки:
требования к товару, под которые подходит продукция одного производителя (ст. 33 44-ФЗ).
Годы решений: 2018-2026. Выгрузка: 2026-11-15.

Автор: Илья Трапезников, [Портал ТЗ (tzfz.ru)](https://tzfz.ru/praktika-zatochka).

## Главное в цифрах

- Исход подтверждён по тексту решения в 1 527 делах из 1 553.
- В пользу заявителя (обоснована или обоснована частично): 704, это 46,1 %.
- Интерактивная статистика по регионам, годам и категориям: https://tzfz.ru/praktika-zatochka/statistika

## Файл data.csv

UTF-8 с BOM, разделитель точка с запятой, дробные числа с запятой (так файл сразу открывается
в русском Excel). Одна строка - одно решение.

## Как собрано

Источник - официальный реестр жалоб ЕИС (zakupki.gov.ru/epz/complaint). Для каждого системного
заявителя реестр пройден целиком, исход каждого дела взят из текста решения, а не из статуса
карточки: статус на карточке неоднократно расходился с резолютивной частью. Документы без
текстового слоя распознавались. Дубли убраны по идентификатору документа решения, а не по номеру
извещения: на одну закупку бывает до шести разных жалоб.

## Чего датасет не показывает

- Это не срез по стране: это практика семи системных заявителей в одной товарной нише
  (звук, свет, музыкальные инструменты для бюджетных учреждений) плюс разовые дела.
- Долю жалоб на характеристики среди всех жалоб посчитать нельзя: датасет по построению состоит
  только из таких дел.
- Срок рассмотрения посчитать нельзя: есть дата решения, нет даты подачи.
- 2022 и 2023 годы представлены единичными делами. Это пробел в сборе, а не спад активности,
  поэтому тренд по нему строить нельзя.
- Признаки нарушения выделены по нашему пересказу сути дела, а не по формулировкам ФАС.

## Обезличивание

В файле нет имён и фамилий заявителей, названий заказчиков, ИНН, номеров дел и извещений,
ссылок на документы. Цель набора - паттерны нарушений, а не поиск виновных. Сами решения ФАС
открыты в реестре ЕИС.
